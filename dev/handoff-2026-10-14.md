## 构建与测试工具

- Node >=22.18，继续零 npm 依赖，类型擦除不是类型检查。
- 两个原生目标都是无依赖单文件，`build-app.sh` 用 xcrun swiftc 编译 arm64 和 x86_64 后 lipo。
- 版本、构建号可通过 VERSION / BUILD_NUMBER 设置。
- CHANNEL=local 是默认本地 ad-hoc 签名，无沙盒；developer-id 用 Developer ID + runtime，
  无沙盒；app-store 才带 House.entitlements。发布渠道需要 SIGN_IDENTITY。
- RELEASE=1 兼容映射 developer-id，preflight 与构建渠道一致。尚未做真实发布证书签名、公证或上架。
- COPY_TO_DESKTOP=0 可以只生成 dist。ICON_FALLBACK 仅是图标转换失败时显式指定旧图标的备用口；
  本轮最终包由同一 IconRender 代码重新生成图标，没有使用备用图标。
- 执行沙箱中 SwiftPM 嵌套沙箱失败、原生 App 返回 134、iconutil 报 Invalid Iconset。
  使用普通本机会话后原生测试与 iconutil 正常。本轮没有关闭任何系统安全设置。
- --shot / --uitest / --probe-blank 都使用 nonPersistent WebKit 数据库，测试不清玩家存档。
- 反证在临时复制的源码与 App 中运行，强制中止不会留下正式源码污染。
- Bash 3.2 下变量接中文标点必须加花括号；本轮修掉正常、错误和统计分支。
- 截图偏好用 JSON.stringify 写入，修掉旧的多重转义；SHOT_OUT 可指定新目录，缺图会退出非零。
  snap=1 自动开局，所以开局选择器场景仍用不带 snap 的查询。
- 界面反证先验完整基线，按说明先跑直接相关档；未抓到必须回退全套。
  同批注入复用刚实测的时钟，不把耗时伪装成通过。ONLY / MODES 仍是局部验证，须如实说明。
